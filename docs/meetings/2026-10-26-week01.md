## 1 议题与结论

### 1.1 用户端形态：微信小程序 → 移动 H5

- 任务书允许“Vue3 + Vant（H5）或微信小程序”。当前不具备小程序账号、认证与发布条件。
- **结论**：用户端采用移动 H5（Vue 3 + Vant），课程演示用手机浏览器或桌面浏览器设备模拟完成。
- 影响：登录使用“手机号 + 固定验证码 1234”的模拟流程；支付使用模拟支付；两者都需在 SRS 与答辩材料中明确标注“课程模拟，不接真实服务”。

### 1.2 需求范围

确认课程范围内必须完成的两条端到端闭环：

1. 用户：浏览 → 加购 → 下单 → 模拟支付 → 查单；
2. 管理端：登录 → 菜品管理 → 订单接单/派送/完成。

确认**不做**：微信小程序、真实支付与短信、骑手端、多门店、优惠券/积分、图片上传服务、消息推送。
上述不做项已写入 `docs/requirements/SRS.md` 第 2.4 节。

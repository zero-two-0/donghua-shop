## 上周任务完成情况

1. 第 1 周 需求基线：完成任务书分析，确认用户端放弃微信小程序、改用任务书允许的 Vue 3 + Vant H5；确定两人分工；把原 12 周计划收敛为 8 周，明确每周一个主要交付包；建立 Git Flow（main / develop / feature / release / hotfix）与 PR 互审规则。

2. 第 2 周 设计基线：完成技术方案（Java 17 + Spring Boot 2.7 + MyBatis + MySQL 8；Vue 3 + Vite；JWT 双域认证；事务与并发口径）与数据库设计（11 张表：employee、user、category、dish、dish_flavor、setmeal、setmeal_dish、address_book、shopping_cart、orders、order_detail，含逻辑外键、状态 CHECK 与索引），并给出空库建表脚本与数据字典。

3. 第 3 周 接口契约：一次性设计并冻结 63 个 HTTP 路径（用户端登录/分类/菜品/套餐/购物车/地址/订单/催单；管理端员工/分类/菜品/套餐/营业状态/订单处理/统计/工作台），统一 code/msg/data 外壳、Bearer 鉴权、page/pageSize 与 total/records 分页、金额后端重算、订单状态 1~6 与支付状态 0~2；配套 A/B/C 三批评审工作表。

4. 第 4 周 后端交付：完成三模块后端（sky-common / sky-pojo / sky-server，175 个文件），课程适配含白名单测试登录、PBKDF2 加盐口令、令牌双域隔离、资源归属校验、购物车数量修正、订单服务端计价与事务快照、模拟支付、条件状态迁移、营业状态与工作台统计、静态资源与 /openapi.yaml 托管；50 项自动化测试全部通过（H2 + MockMvc），契约静态一致性脚本核对 63 个路径与 72 个 Schema。

5. 前端交付（提前完成）：用户 H5（Vue 3 + Vant）12 个路由——登录、分类与搜索、菜品详情与口味、套餐详情与组成、购物车、确认订单、模拟支付、订单列表/详情/取消/再来一单/催单、地址增删改查与默认、个人中心、打烊提示；管理 Web（Vue 3 + Element Plus）7 个页面——登录、工作台（经营数据/订单计数/营业额报表）、订单查询与接单/拒单/取消/派送/完成、分类、菜品、套餐、员工管理，顶栏含营业状态开关。

6. 真实联调（补齐后端报告中“未验证”的真实库部分）：按第 2 周 schema.sql 建课程库 takeout_course（11 张表，种子 2 分类 / 2 菜品 / 1 套餐 / 2 用户 / 2 地址），用项目内 JDK 17 + Maven 3.9.9 打包成功，JAR 连真实 MySQL 启动并监听 8080；编写 37 项接口冒烟脚本，按“登录→浏览→加购→改数量→建地址→下单→模拟支付→员工接单→派送→完成→统计”跑完整链路，结果 37/37 通过。

7. 工程化与交付物：统一仓库结构（code/backend、code/frontend、docs/leader、docs/integration）；脚本化环境搭建、建库、构建、启停、接口冒烟与环境自检；补齐页面-接口对应表、契约差异对照、缺陷台账、联调记录、前端自测、运行手册、GitHub 操作指引；完成 Git 初始化（main/develop 双分支、提交身份为本组邮箱）并配置远程仓库。

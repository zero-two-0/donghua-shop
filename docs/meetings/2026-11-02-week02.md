## 2 需要会议拍板的三件事

### 2.1 素材复用边界

- 组员侧检查结论：计划书列出的三个素材路径均为 macOS 路径，本机不存在；旧 `DonghuaShopSpring` 为 Spring MVC + JSP 单体，架构不匹配，只能参考实体划分。
- 建议决议：**不依赖素材交付**，两端均自研；若组长后续提供素材，只用于“页面信息架构参考”和“SQL 字段对齐”，复用范围与改动须写入课程技术报告。
- 〔待确认〕由组长决定是否仍按原计划“复用后端 SQL、DTO/VO 与业务流程”。

### 2.2 技术栈与版本

- 前端：Vue 3 + Vite 6 + Pinia + Vue Router（hash）+ Axios；用户端 Vant 4，管理端 Element Plus 2.9。
- 后端：Java 17 + Spring Boot 3 + MyBatis + MySQL 8（待组长确认 Spring Boot 具体版本）。
- 不引入 Redis（第 1~3 周），登录态用 JWT，购物车落 MySQL。
- 〔待确认〕Spring Boot 3 与 Java 17 的组合、是否使用 Spring Security。

### 2.3 部署方式

- 开发期：Vite 代理 `/api` → `127.0.0.1:8080`，后端无需配 CORS。
- 演示期：Nginx 托管两套 `dist` 并反代 `/api`；或直接用 Vite dev server 演示（风险：依赖开发环境）。
- 建议：第 8 周前用 Nginx 方案；本周不投入部署时间。

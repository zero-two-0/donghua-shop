## 5 复现命令

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
. .\scripts\env.ps1
.\scripts\run-backend.ps1                      # 或 .\scripts\start-all.ps1
node scripts\smoke-api.mjs                     # 主流程 37 项
node scripts\smoke-authz.mjs                   # 权限 22 项
# 静态托管验证（等价 Nginx 规则）
node scripts\serve-dist.mjs code\frontend\user-h5\dist 8081
node scripts\serve-dist.mjs code\frontend\admin-web\dist 8082
node scripts\check-static-deploy.mjs           # 13 项
```

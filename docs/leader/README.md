## 3 阅读与复核顺序

先读 SRS 和总体计划确认范围，再读技术/数据库设计，按 OpenAPI 和分批评审表检查接口，最后按后端 README 复现报告中已经执行的构建与测试。涉及数据库初始化或迁移时，先审阅 SQL 并取得操作授权，不对个人现有库自动执行。

如果要验收完整浏览器闭环，还需要第 5 周前端、第 6 周联调、第 7 周系统测试和第 8 周部署包。本轮不能把这些未来活动写成已经通过，也不把 `code/h5-demo/` 的旧演示作为正式 Java 后端或组员已完成成果。

## 4 本人交付检查清单

- 需求、技术、数据、契约、后端和测试材料分别有入口，统一为两人 / 八周 / Java17 / H5 / 模拟支付。
- 正式 API 使用 `code/msg/data`，Bearer 调用规范以 OpenAPI 为准；对照代码时检查字段、路由与状态。
- 队友评审、冻结、会议、Git PR、部署和真实环境测试均需真实证据；没有证据就写待执行或未验证。
- 不把私人密钥、数据库密码、完整 token 或真实个人信息放入配置、示例和报告。
- 本次没有因此自动初始化 Git、提交、推送或公开部署。后续协作按规范保留真实过程记录。
